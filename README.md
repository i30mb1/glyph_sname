# Glyph Snake

## Short Description

**English:** Feed the hungry snake! Tilt your phone to move and collect tasty treats. The more you eat, the longer you grow!

**Русский:** Накорми голодную змейку! Наклоняй телефон, чтобы двигаться и собирать вкусняшки. Чем больше съешь — тем длиннее станешь!

## About

Glyph Snake is a classic snake game designed for Nothing Phone's Glyph Matrix display. Control the snake by tilting your phone in any direction — the gyroscope detects your movements and guides the snake accordingly.

The game runs on the LED matrix on the back of your Nothing Phone, turning it into a retro gaming device.

### Features
- Gyroscope-based tilt controls — works in any phone orientation
- Progressive difficulty — snake speeds up as you eat more
- Visual feedback on Glyph Matrix display
- Supports Nothing Phone (2a)

### How to Play
1. Open the game from Glyph Developer Kit
2. Long press to start
3. Tilt your phone to move the snake
4. Eat the blinking food to grow
5. Avoid hitting yourself!
6. Long press to restart after game over
